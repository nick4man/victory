## Проверка перед push

```bash
# 1. Что уйдёт в коммит
git diff --cached --stat

# 2. Поиск типичных утечек в staged-файлах
git diff --cached | grep -nEi '(\+7|8)\s?\(?9\d{2}|token|secret|password|api[_-]?key|\.env' || echo "чисто"

# 3. Никаких бинарников (фото/видео — в Nextcloud, в репо только ссылки)
git diff --cached --name-only | grep -Ei '\.(jpg|jpeg|png|mp4|mov|pdf|docx?)$' && echo "ВНИМАНИЕ: бинарник в коммите"
```
