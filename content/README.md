# Контент-маркетинг АН «Виктори»

Материалы контент-плана агентства: YouTube, Shorts, статьи для сайта, соцсети.

**Почему в репозитории сайта:** контент ссылается на разделы и объекты
victory62.org; правки контента и сайта ревьюятся в одном процессе (PR → main).

## Структура

| Каталог | Что лежит |
|---|---|
| `plans/` | Контент-планы по месяцам (`2026-12.md`, …) |
| `youtube/` | Сценарии, SEO-шаблоны (заголовки, описания, теги), статистика канала |
| `articles/` | Тексты для раздела «Новости» сайта |
| `assets/` | Обложки, шаблоны (ссылки на Nextcloud, бинарники не коммитим) |
| `playbooks/` | Регламенты: как готовим ролик, как публикуем, чек-листы |

## Правила

1. **Без чувствительных данных.** Репозиторий публичный: никаких телефонов
   клиентов, персональных данных, цен «из CRM» вне опубликованных объектов,
   токенов и доступов. Перед коммитом — чек-лист из
   `playbooks/pre-publish-checklist.md`.
2. **Ветка `content/<тема>` → PR в `main`.** Прямые пуши в `main` запрещены
   (общее правило репозитория).
3. Даты — `dd.MM.yy`, язык — русский.
4. Каждый ролик/статья обязаны ссылаться на раздел сайта (каталог, оценка,
   ипотека) — контент работает на сайт, сайт — на контент.

## Источники правды

- Сайт: https://victory62.org
- Статистика YouTube: `youtube/stats/` (обновляется вручную из YouTube Studio)
- Бизнес-регламенты: `.claude/docs/reglament/`
