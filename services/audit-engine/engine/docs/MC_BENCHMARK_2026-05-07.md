## Сходимость
- |mean(1M) − mean(10M)| = 1×10⁻⁴ — внутри SE на 1M (~9×10⁻⁵).
- |p5(100k) − p5(10M)| = 3×10⁻⁴; |p95(100k) − p95(10M)| = 1.6×10⁻³.
- На 100k значимая дрожь в хвостах (p95), на 1M — стабильно.

## Решение
- `mc_default_simulations = 1_000_000` — production-N для онлайн-API.
- `mc_max_simulations = 10_000_000` — потолок для офлайн/критических кейсов.
- `mc_async_threshold = 50_000` — всё, что > 50k, уходит в threadpool под семафором.

```bash
/tmp/mc_bench.sh   # (см. содержимое в коммите)
```
