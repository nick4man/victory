# Real Estate Estimator Skill (v4.0 — Live Search)

Скилл для автономной оценки недвижимости по методу аналогов.
**Главное правило: никаких заглушек и выдуманных данных. Только реальные результаты поиска.**

---

## 1. Классификация объекта

Определи тип из запроса:
- **flat** — квартира, студия, апартаменты
- **house** — дом, таунхаус, дача, коттедка
- **land** — участок, земля, ИЖС, СНТ
- **commercial** — офис, торговое, склад, коммерция

---

## 1.1. РЕЖИМЫ (ОБЯЗАТЕЛЬНО)

- **Express Mode (Default)**: Только оценка рыночной цены по аналогам. Выполняется самостоятельно.
- **Audit/Content Escalation**: Если в запросе есть ключевые слова Аудита (EI, инвест-анализ) или Контента (напиши статью, пост) — СТРОГО использовать соответствующие гейты (`audit-escalation-gate` / `media-escalation-gate`) для передачи задачи Генералу.

## 3. Алгоритм поиска аналогов (ОБЯЗАТЕЛЬНЫЙ)

### Шаг 1: Поиск через web_search (ОБЯЗАТЕЛЬНО, НЕ ПРОПУСКАТЬ)

⚠️ **КЛЮЧЕВОЕ ПРАВИЛО v4.1 — РАЗДЕЛЯЙ ЗАПРОСЫ ПО ПЛОЩАДКАМ!**
НЕ делай один запрос `site:cian.ru OR site:avito.ru OR site:realty.yandex.ru` — Brave вернёт только первый сайт.
Делай **отдельный запрос на каждую площадку** (минимум 3 запроса: Cian, Avito, Яндекс.Недвижимость).

Выполни **3–4 поисковых запроса** через инструмент `web_search` — по одному на площадку:

```
query_cian:   "[город] [улица] продажа [тип] цена site:cian.ru"
query_avito:  "[город] [улица] продажа [тип] site:avito.ru"
query_yandex: "[город] [улица] продажа [тип] цена site:realty.yandex.ru"
query_dom:    "[город] [тип] [комнаты] продажа site:domclick.ru"  # опционально
```

**Конкретный пример для «Рязань, Горького 50, 2-комн, 54 кв.м»:**
```
query1: "Рязань Горького 2-комнатная квартира продажа цена site:cian.ru"
query2: "Рязань Горького 2-комнатная квартира продажа site:avito.ru"
query3: "Рязань Горького 2-комнатная квартира продажа цена site:realty.yandex.ru"
query4: "Рязань Горького 2-комнатная квартира вторичка site:domclick.ru"
```

### Шаг 2: Извлечение данных из результатов

Из каждого найденного объявления извлеки:
- **URL** — полная ссылка (cian.ru, avito.ru и т.д.)
- **Цена** — в рублях
- **Площадь** — кв.м
- **Цена/кв.м** = Цена ÷ Площадь
- **Описание** — краткое (этаж, ремонт, особенности)

### Шаг 3: Фильтрация и отбор

- Отбери **5–8 наиболее релевантных аналогов**
- Фильтруй по: схожей площади (±20%), схожему типу, тому же городу/районе
- Отброси явно нерелевантные (другой город, коммерция вместо жилья и т.д.)

### Circuit Breaker

Если web_search вернул 0 результатов по профильным сайтам — попробуй более широкий запрос без site-фильтра. Если снова пусто — сообщи специалисту и попроси уточнить параметры. **НЕ ВЫДУМЫВАЙ ДАННЫЕ.**

## 5. Режим работы (Авто vs. Черновик)

### Режим «Черновик» (по умолчанию для одиночных запросов):
1. Выполни поиск и сформируй отчёт по структуре выше.
2. В конце добавь вопрос: **«Отчёт готов. Вносим правки или всё ок?»**

### Авторежим (в группах или когда специалист явно сказал «без черновика»):
- Сразу выдать финальный отчёт без лишних вопросов.

---

## 6. Уточнение данных

Если в запросе **не указаны критически важные параметры** — уточни перед поиском:
- Площадь объекта (без неё расчёт цены/м² невозможен)
- Тип объекта (если неясно из контекста)

**Этаж и состояние** — желательны, но не блокируют запуск.

---

## 7. Важные ограничения

- **ЗАПРЕЩЕНО** выдавать выдуманные URL или несуществующие объявления
- **ЗАПРЕЩЕНО** использовать `parse.py` как единственный источник данных (он — вспомогательный)
- Ссылки должны вести на реальные страницы реальных площадок
- Если web_search не находит прямых ссылок на объявления — честно укажи это и дай общий диапазон цен по рынку на основе найденных текстовых данных

---

## 8. Технический fallback (parse_real.py)

Если нужно автоматически собрать аналоги через скрипт (например, в pipeline):

```bash
# С ключом Brave API
BRAVE_API_KEY=<ключ> python /opt/.openclaw/.openclaw/workspace/skills/real-estate-estimator/scripts/parse_real.py "Ставрополь Горького 2-комн 54м" --type flat --limit 8
```

Скрипт возвращает JSON с полями: `url`, `price`, `area`, `price_sqm`, `desc`, `source`.
