API создания отчетов позволяет реализовать
следующие действия:
```
 1. Создавать новый вид отчета для конкретного раздела (например "Продавцы")
 2. Редактировать название и позицию уже созданного отчета
 3. Удалять ранее созданный отчет
 4. Получать список всех созданных отчетов
 5. Получение справочника разделов в Topnlab где есть возможность создать свой отчет.
 6. Генерацию отчета и отправку его пользователю
```
## 1. Создавать новый вид отчета

```
https://agencies-p.topnlab.ru/public/menu/create?key=mykey&title=Новый&p
age_id=1&order=
10&url=http://my-server/generate
```
Параметры:
ВАЖНО!!! Все параметры обязательные!! при создании запрос должен содержать все атрибуты!!!
```
   key - в нем передается ключ, предоставленный сотрудниками Topnlab.
   title - Название отчета, текст выводится в меню массовых действий у пользователей
   системы
   page_id - идентификатор страницы, где будет доступна генерация отчета
   order - порядковый номер (В начале списка, сверху будет порядковый номер 1)
   url - адрес, на который будет вы будете получать данные по этому отчету
```

## 6. Генерация отчета и отправку его пользователю
Для генерации отчета на URL который вы указали при создании отчета, будут приходить данные
для генерации отчета на стороне Клиента
Topnlab отправляет данные POST-запросом в формате JSON:

```
{
        user: { // Данные авторизованного пользователя
           fathername: "Артушович",
           firstname: "Арам",
           lastname: "Пепанян"
           role: 1,
           role_name: "Агент",
           status: 0
           id: 28028,
           email: "email@example.com",
           phone_num: "9110000000"
           department_id: 900,
           department_name: "Отдел аренды",
        ],
        ids: [123234, 123456], // идентификаторы выбранных карточке
        report_id: 7 // Идентификатор типа отчета
]
```
Сторонний сервер должен ответить в Topnlab формате JSON вида ссылка на скачивание
подготовленного файла на стороне клиента:

```
{
    url: "http://s3.aws.website.com/report20221222.pdf"
}
```
Ссылка на файл, переданная в свойстве url будет отправлена в браузер пользователя на
скачивание.
Если в течении 10 секунд после отправки данных Topnlab не получает ссылку на файл то считает
ошибкой.


Важно!
Для того чтобы пользователь мог скачать файл по ссылке при отдаче файла ваш сервер должен
передавать вместе с файлом HTTP-заголовки:


```
 Access-Control-Allow-Origin: *
Access-Control-Allow-Headers: *
```
В ПРОТИВНОМ СЛУЧАЕ ФАЙЛ НЕ БУДЕТ СКАЧИВАТЬСЯ У ПОЛЬЗОВАТЕЛЯ
Пример кода PHP по добавлению заголовков:

```
<?php
  header('Access-Control-Allow-Origin: *');
  header('Access-Control-Allow-Headers: *');
  // Дальше идет код передачи содержимого файла
```
Для проверки все ли передается правильно проверьте ссылку на отчет на сайте
https://cors-test.codehappy.dev/ На странице проверки должна появится зеленая галочка с текстом
"This URL will work correctly with CORS."
