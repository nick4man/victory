## Итог сквозного ревью

**55 строк SLA в пяти таблицах. Машинно измеримых — ноль.** Сорок с лишним находок сводятся к
четырём причинам, разобранным в [DESIGN.md §2](DESIGN.md):

1. **Нет сущности «объект в работе».** `LeadEvent` покрывает воронку покупателя (Шаги 4–5); для
   Шагов 1–3 нет ни модели, ни состояний.
2. **Завершение шага — свободный текст.** Пять разных фраз в чат, ни одна не парсится → дедлайны не
   с чего отсчитывать.
3. **Работа ведётся в системе без исходящих событий.** У TopNLab нет task-API; у нас есть `Task` со
   всем нужным.
4. **Три конкурирующие схемы путей в Nextcloud** — регламенты, `DealFolderResolver`, приёмник фото
   work-bot.
