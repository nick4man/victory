# Feeds submission playbook — Yandex Недвижимость / Cian / Avito

Phase 1b плана `merry-honking-kay.md` — manual ops для подачи наших feed URLs на агрегаторы. После approval — crawler caждого подхватывает обновления автоматом каждые ~30 мин (наш cache TTL).

## Наши feed URL'ы (production, HTTP 200, 30-min cache)

```
YRL    https://victory62.org/feeds/yrl.xml     — 23 offers   (Yandex schema)
Cian   https://victory62.org/feeds/cian.xml    — 23 objects  (Cian schema)
Avito  https://victory62.org/feeds/avito.xml   — 70 ads      (Avito schema)
```

---

## 1. Яндекс Недвижимость (бывш. partner.yandex.ru/realty → 404)

**ВАЖНО:** `partner.yandex.ru/realty` deprecated. Сейчас всё через
`realty.yandex.ru/management-new/`.

### Шаг 1 — Войти в Я.Аккаунт

`https://passport.yandex.ru/auth` под account'ом, который должен владеть
агентским кабинетом. Один Я.Аккаунт = один партнёр. Использовать ROBUST
account, не личный — потеряешь доступ если кто-то уволится.

### Шаг 2 — Открыть кабинет

`https://realty.yandex.ru/management-new/`

Первый заход — Я.попросит подтвердить телефон и согласие с условиями
оферты. Это нормально.

### Шаг 3 — Сменить тип аккаунта на «Агентство»

В кабинете → **Настройки** (правый верх, иконка шестерёнки) → секция
«Тип кабинета».

- По умолчанию: **«Собственник»** — каждое объявление вручную.
- Нужно: **«Агентство»** — поддерживает XML feed.

Нажми «Сменить» → введи:
- **ОГРН/ОГРНИП** агентства (15 / 13 цифр)
- **Юридическое название** организации

⚠️ **Это необратимо.** «Вернуться к собственнику» — не получится. Дважды
проверь ОГРН перед сохранением.

### Шаг 4 — Валидировать feed через Я.Вебмастер

ДО подачи в кабинет — прогнать через Webmaster. Это спасёт время.

1. `https://webmaster.yandex.ru` → твой site (victory62.org)
2. Левое меню → **«Инструменты»** → **«Проверка XML-фида»**
3. Тип фида: **«Недвижимость»**
4. URL: `https://victory62.org/feeds/yrl.xml`
5. Submit → дождаться отчёта (~30 сек)

Если зелёная галочка — фид валидный, идём дальше. Если ошибки — фикс
ить с нашей стороны (`app/views/feeds/yrl.xml.builder`).

### Шаг 5 — Добавить feed в кабинете

В `realty.yandex.ru/management-new/`:

- Левое меню → **«Импорт объявлений»** (или «Источники объявлений»)
- Кнопка **«Добавить фид»**
- URL: `https://victory62.org/feeds/yrl.xml`
- Формат: **YRL** (Yandex Realty Language)
- Расписание обновлений: **«Каждый день»** (или каждые 2 часа если
  доступно — мы кэшируем 30 мин, лишний раз не нагрузит)

### Шаг 6 — Дождаться модерации

- **SLA 3-7 дней** для нового агентства
- Email-уведомление о результате
- Если reject — в письме конкретные причины. Типичное:
  - Некорректный feed schema (cм. шаг 4)
  - Слишком мало объявлений (нужно ≥ 10 — у нас 23 ✓)
  - Дубли с другим зарегистрированным feed'ом

### Если ошибка прямо сейчас

Что user видит на `partner.yandex.ru/realty`:
- **404 — URL deprecated.** Иди на `realty.yandex.ru/management-new/`
- **«Сначала войдите»** — нужен logged-in Я.Аккаунт
- **«Кабинет недоступен»** — region restriction. Свяжись с
  поддержкой через форму на `realty.yandex.ru/promotion/`
- **«Не можем верифицировать ОГРН»** — проверь на `egrul.nalog.ru`
  что ОГРН активен. Иногда нужно 1-2 рабочих дня после регистрации
  ИП/ООО для появления в базе

## 2. ЦИАН (business.cian.ru)

### Шаг 1 — Регистрация агентского кабинета

`https://www.cian.ru/users-pro/` → «Стать партнёром» → «Я — агентство»

Введи:
- ИНН организации
- Контактное лицо + телефон
- Город (Рязань)
- Кол-во агентов

ЦИАН-менеджер обычно перезванивает в течение дня. **Услуга платная** —
тариф зависит от региона + объёма размещений. Рязань — небольшой рынок,
обычно базовый тариф (1-3к ₽/мес базовая видимость + платное продвижение
поверх).

### Шаг 2 — Получить access к импорту

После активации тарифа — менеджер откроет в кабинете секцию **«Импорт
объявлений»** (по умолчанию закрыта).

### Шаг 3 — Добавить feed

`business.cian.ru` → **«Импорт»** → **«Источники данных»** → «Добавить»

- Тип: **«XML feed (CIAN format)»**
- URL: `https://victory62.org/feeds/cian.xml`
- Расписание: каждый день в 03:00 МСК (наш cache к утру свежий)

### Шаг 4 — Модерация 1-3 дня

После первой успешной обработки — все 23 объекта появятся в их каталоге.
Каждая следующая публикация — почти моментальная (только новые
объявления модерируются).

## 3. Avito (autoload)

### Шаг 1 — Avito Pro account

`https://www.avito.ru/autoload`

Залогиниться под Avito-аккаунтом агентства (НЕ личный). Если ещё нет
— зарегистрировать на `https://www.avito.ru/auth/register`.

Категория: **«Недвижимость»** → выбрать «Профессионально продаю
недвижимость» → войти в Avito Pro.

### Шаг 2 — Подключение Автозагрузки

В Avito Pro → **«Кабинет»** → **«Автозагрузка»** (если её нет — нужно
пройти модерацию агентства, ~1 день).

### Шаг 3 — Добавить feed

«Автозагрузка» → **«Добавить файл»** или **«Добавить URL»**

- Источник: **«XML по ссылке»**
- URL: `https://victory62.org/feeds/avito.xml`
- Имя источника: «АН Виктори — main feed»
- Расписание: «каждый день» (Avito дёргает один раз)

### Шаг 4 — Тестовая выгрузка

В кабинете — кнопка **«Запустить вручную»**. Avito скачает feed, прогонит
валидацию, покажет:
- Сколько объявлений распознано
- Сколько пройдут модерацию
- Сколько с ошибками (нужно фикс ить feed)

Если 0/70 распознано — это значит structure mismatch. У нас feed
работает (70 ads), значит проблема обычно в обязательных полях которые
Avito ждёт но мы не отправляем (контактный телефон менеджера, главное
фото).

### Шаг 5 — Модерация ~1 сутки

После первого успешного scan — модерация per-объявление. Стандартно
объекты появляются через 6-24 часа.

⚠️ Avito бесплатный для базового размещения, но **тариф для агентств
есть в Рязани** — без оплаты можно публиковать ~5-10 объектов/месяц.
Для всех 70 нужен «Расширенный» тариф.

## 4. Общие проблемы + троaubleshooting

### «Feed недоступен из их стороны»

Проверь что наш сайт доступен извне (не только через VPN):
```bash
curl -I https://victory62.org/feeds/yrl.xml
# expect: HTTP/2 200, content-type: application/xml
```

Если 200 OK + content-type XML — feed виден. Если 5xx — проблема на
нашей стороне (puma down? VDS issue?).

### «Не хватает обязательных полей»

Каждый агрегатор требует свой минимум. Известные мандаторные поля:
- **YRL:** internal-id, type, property-type, location.country/region/locality, price, area, sales-agent
- **Cian:** ExternalId, Category, Address, Url, Phones
- **Avito:** Id, ContactPhone, Address, Price, Description

Если какой-то конкретный field вылетает — открой issue с конкретным
сообщением, фикс в `app/views/feeds/yrl.xml.builder` (или cian/avito).

### «Слишком мало объявлений»

У нас 23 (YRL/Cian) / 70 (Avito). Минимум обычно 10. Все наши пройдут.
Но если конкретный аггрегатор хочет 50+ — нужно расширить scope
(сейчас `Property.in_advertising` фильтр).

### «Duplicate listing in another feed»

Бывает если тот же объект уже размещён у нас на cian.ru вручную (или
через старого партнёра, например МЛС). В кабинете удаляешь ручное
размещение — feed-version remains.

## 5. После approval — что мониторим

В **Webmaster** (мы уже подключили API):
- `rake yandex:webmaster:summary` — еженедельно проверять SQI + новые impressions
- Через 7 дней после подачи — re-run `rake yrl:baseline`, diff с
  `tmp/yandex_baseline_2026-05-18.json`. Должны увидеть рост сапе SQI
  + новые queries в `top_queries` ("купить квартиру АН Виктори Рязань")

В **Yandex Metrika** (existing setup):
- Source = realty.yandex.ru — clicks от listings → property pages
- Conversion: Inquiry.where(referrer_url ILIKE '%realty.yandex.ru%')

В **Cian/Avito** кабинетах:
- Просмотры объявлений, звонки, отклики
- Conversion: лиды через Cian/Avito → они звонят на телефон в feed
