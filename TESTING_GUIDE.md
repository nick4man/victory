## 🚀 БЫСТРЫЙ СТАРТ ТЕСТИРОВАНИЯ

### 1. Подготовка окружения:

```bash
cd ~/victory

# Установка зависимостей (если еще не установлено)
bundle install
yarn install

# Копирование .env
cp .env.example .env

# Создание БД
rails db:create
rails db:migrate

# Загрузка seed данных
rails db:seed

# Запуск сервера
rails server

# В отдельном терминале - Redis (для ActionCable)
redis-server

# В отдельном терминале - Sidekiq (опционально)
bundle exec sidekiq
```

### 2. Открыть в браузере:
```
http://localhost:3000
```

### 3. Тестовые аккаунты (из seed):
```
Admin:
  Email: admin@viktory-realty.ru
  Password: Password123!

Agent:
  Email: agent1@viktory-realty.ru
  Password: Password123!

Client:
  Email: client1@viktory-realty.ru
  Password: Password123!
```
